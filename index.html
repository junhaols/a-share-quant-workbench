        02核心概念与避坑速查

        4 大策略体检指标

        年化收益 (CAGR) 看长期复利；最大回撤 看最坏亏多少；夏普比率 看单位风险回报（>1 及格，>2 优秀）；费用占比 看是否给券商打工。

        未来函数（Look-ahead Bias）

        回测偷看未来信息的 Bug。铁律：决策只用已公开历史，成交必须晚于信号（T日信号 → T+1日开盘成交）。

        Walk-Forward & 参数高原

        用过去 3 年挑参数，锁定后跑未知的第 4 年样本外行情，拼接真实曲线；选参数只看连续稳定的“参数高原”，远离孤立极值，并用分批错峰调仓（Tranching）消除择日运气。

        大模型辅助量化的正确姿势

        让 LLM 做盘后情绪打分、风控提示、回测挑刺与代码起草；绝不要直接把 K 线价格丢给大模型预测明天涨跌。

        04大模型量化

        LLM × Quant

        让大模型读懂数字背后的信息，而不是猜明天的涨跌

        大模型擅长把非结构化的文本变成结构化信号、自动化研发流程、做多角度审查；它不擅长直接预测价格，而且会把训练期间见过的历史行情“记住”。这一页把能做的事按成熟度分层，并给出本站的真实链路、评测纪律和可以直接用的提示词。

        适合交给 LLM

        • 新闻、公告、研报 → 情绪与事件因子
        • 盘后数据 → 结构化复盘与风控提示
        • 因子假设、回测代码起草与红队审查
        • 多角色辩论，暴露单一视角的盲点

        不要交给 LLM

        • 直接把 K 线丢进去预测明日涨跌
        • 让模型自己计算收益率、回撤等数字
        • 无规则约束地直接决定仓位与下单
        • 在模型训练期内的历史上“回测”LLM 信号

        1. 代码
          拉取行情

          AKShare 拉 A 股 ETF，yfinance 拉美股 ETF，写入前复权日线 JSON。

        2. 代码
          计算指标与信号

          1/5/20 日涨跌、20 日波动率、是否站上 MA20、20 日动量 Top2 + 避险切换的目标仓位。

        3. 代码
          压缩成上下文

          只把算好的数字和信号标签传给模型，不传原始 K 线，也不传 API Key 之外的任何账户信息。

        4. LLM
          结构化解读

          deepseek-flash，temperature 0.2，JSON 模式输出情绪分、定调、分市场要点、风险与纪律提示。

        5. 代码
          校验与兜底

          解析 JSON 并逐字段校验；关键指标卡始终使用代码计算的数字；调用失败或没有 Key 时自动回退到规则引擎。

        6. 代码
          归档与展示

          写入 daily_snapshot.json 和近 30 天的 ai_brief_history.json，推送后网页自动刷新。

        设计原则：数字由代码负责，文字由模型负责，任何一步失败都不会让网页出现编造的数字。
